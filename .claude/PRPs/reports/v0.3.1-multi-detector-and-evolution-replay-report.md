## Summary

Two features, both delivered:

1. **Multi-detector strategies.** The linear composer now maps N detector stages to N branches
   sharing one policy/confirmation set, and an operator-chosen eligible-detector pool rides in
   `graph.meta.evo.eligible_detectors` to constrain what `mutator.graph-edit` may swap in or add.
2. **Evolution replay.** The Evolution tab is a campaign → generation → member sidebar plus an
   animated candlestick replay with entry/stop/target overlays, backed by two new read-only
   endpoints that re-derive trades deterministically without touching the trial ledger.

Orchestrated across five Sonnet subagents on disjoint file sets, with Opus reviewing every
deliverable and rejecting one for rework.

- **Replay end-to-end** — real member `20260727-a5ef77:002:0000` (a 3-detector member) returned 541
  bars and 49 trades carrying `stop`/`target`/`pattern`/`planned_rr`.
- **Bar-index mapping** — extracted `evoBsearchFirstGE` verbatim and ran it under node against the
  real replay payload: 49 trades mapped, 0 incorrect lower bounds, 0 mismatches vs a linear
  reference implementation, correct clamping at both ends.
- **Frontend wiring** — `node --check` clean; all 79 `$("id")` references resolve against 88 HTML

## Pre-existing Issues Found (NOT introduced here, NOT fixed)

**A no-op composer save re-hashes the strategy.** `canonical_dict` includes node ids, and
`_graph_to_stages` emits an explicit `data` stage the browser omits, so the ids a strategy gets on
its first save differ from those it gets on reload-and-save. Confirmed against `git HEAD`: on
pre-v0.3.1 code a single-detector graph goes `data/detector-0/policy-1` → `data-0/detector-1/policy-2`,
changing `graph_hash`. It converges after one cycle, and the shipped strategy files are already at
that fixed point (so the README's "bit-identical graph hash" claim holds for them). But a strategy
composed fresh in the browser, gated, then reloaded and re-saved with no edits will orphan its trial
ledger rows. Out of scope for v0.3.1; worth its own fix.
