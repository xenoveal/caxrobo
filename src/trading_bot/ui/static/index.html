Evolution eligibility

Unchecked detectors are excluded from the pool evolution may swap in or add. Detectors already used by this pipeline stay checked and locked in — evolution may prune one, but never re-introduce it. All checked (the default) stores no constraint at all.

Run

Every gate and evolve run adds trials to this campaign's ledger, permanently raising its DSR penalty. Use a scratch name like ui-smoke to explore. Evolving an existing campaign continues improving the population it already paid for, and backtest and gate then score that campaign's champion, not the seed graph on disk — pick a new campaign name to evaluate the seed itself.
